# 🛠 Практическая работа №7: Отладка ПО в Microsoft Visual Studio

## 🎯 Цель работы
Освоение встроенных средств отладки среды Microsoft Visual Studio, поиск и устранение логических ошибок в программном коде, а также работа с системой контроля версий Git.

---

## 💻 Используемые инструменты отладки

В ходе выполнения работы были применены следующие механизмы отладчика Visual Studio:

* 🔴 **Точки останова (Breakpoints)** — для приостановки выполнения программы в ключевых местах.
* ⛑ **Пошаговое выполнение (Step Over / F10)** — для анализа алгоритма строка за строкой без захода в сторонние методы.
* 🔍 **Окно «Локальные» (Locals)** — для автоматического мониторинга состояния всех переменных в текущем контексте.
* 📌 **Инспекция данных (Data Tips)** — просмотр значений переменных при наведении курсора в редакторе кода.
* 📜 **Стек вызовов (Call Stack)** — для анализа последовательности вызовов методов и поиска источника исключений.
* 👀 **Окно «Контрольные значения» (Watch)** — для отслеживания конкретных выражений и изменения их значений в реальном времени.

---

## 📂 Структура проекта и выполненные задачи

Работа разделена на три функциональных блока, каждый из которых зафиксирован в отдельной ветке репозитория:

### 1. 🔢 Приложение «Фибоначчи» (ветка `fibonacci`)
* **Проблема:** Неверный расчет последовательности из-за некорректных начальных условий.
* **Решение:** С помощью точек останова выявлена ошибка в итерации цикла. Логика исправлена, добавлены XML-комментарии.

### 2. 🌌 Приложение «Галактики» (ветка `galaxies`)
* **Проблема:** Возникновение исключения `NullReferenceException` при попытке вывода данных.
* **Решение:** Используя **Call Stack**, найден метод, обращающийся к неинициализированному объекту. Ошибка устранена.

### 3. 🔤 Приложение «Буквы» (ветка `letters`)
* **Проблема:** Демонстрация работы со строковыми массивами и циклами.
* **Решение:** Использовано окно **Watch** для наблюдения за конкатенацией строк на каждой итерации. Код документирован.
